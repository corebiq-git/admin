# COREBIQ Website Starter

A mobile-first, SEO-ready static website starter for COREBIQ.

## Included
- Home
- About
- Products index
- CRM, ERP, Business Flow, Finance, HR, Inventory, Projects, Analytics product pages
- Industries index
- 12 industry landing pages
- Business Flow
- Contact / demo request
- Privacy
- Terms
- XML sitemap
- robots.txt
- Shared Google-style / Material-inspired CSS
- Responsive navigation
- Basic SoftwareApplication / WebPage / CollectionPage / ContactPage structured data

## Deploy
Upload the contents of this folder to your web host or GitHub Pages.

## Important production changes
1. Replace `https://corebiq.com` if the production domain differs.
2. Replace `hello@corebiq.com` in `assets/js/site.js` with the real enquiry email.
3. Connect the contact form to your production backend/Firebase/CRM.
4. Add your real logo, OG image and favicon.
5. Add Google Search Console and submit `/sitemap.xml`.
6. Add real product screenshots and case studies.
7. Review Privacy Policy and Terms with the appropriate legal/business requirements before production.

## Suggested next phase
Connect these public pages to the COREBIQ application at your app/subdomain, while keeping the marketing site separately crawlable.
